# Web Calculator

My first ICT project, developed during my first semester as part of my learning journey in Information and Communication Technology (ICT).

A simple and user-friendly web calculator built using HTML, CSS, and JavaScript.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Simple and clean user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- `index.html` – Main structure of the calculator.
- `style.css` – Styling and layout.
- `script.js` – Calculator functionality.

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your web browser.
3. Start using the calculator!
